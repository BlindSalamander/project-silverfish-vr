Project Silverfish VR 1.0.1 (build 6.6.55) by Blind

Full motion-controlled VR for Project Silverfish: tracked hands, guns held and aimed in the hand, two-handed long guns, room-scale body, helmet HUD, pointer menus, an on-screen keyboard for terminals, a left-handed mode and four graphics presets.

## IMPORTANT
- Steam Frame controllers only, through SteamVR (OpenVR).
- Start the game with the launch option -dx11.
- UEVR nightly (tested: 01143, commit 4ee5c6b).
- After injecting, click once on the game's window.
- Settings: hold both stick clicks for a second, then "Silverfish VR settings".

## The following UEVR settings are controlled by the mod
- Aim Method
- 2D Screen Mode
- D-Pad Shifting
- Ghosting Fix
- L3 + R3 long press for the UEVR menu
- Motion controls inactivity timer
- AHUD compatibility
- UI Distance, UI Size, UI offsets
- Roomscale Movement

Controls, every setting, frame rates, known issues and how to report a bug: README-Silverfish-VR.md in this folder.
